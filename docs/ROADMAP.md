## P2（扩展）
- 云端执行、更多模型供应商适配、调度策略 A/B 与更细粒度成本优化

## 缺失依赖与风险说明
- 本机无 Docker：沙箱相关功能在装有 Docker 的环境验证前一律标注未验证。
- 本机非 Windows：安装包验证必须在 Windows 机器完成。
- 端到端成功执行依赖用户提供可用的 OpenAI 兼容供应商 Key；无 Key 时系统只会如实失败，这是设计行为。
